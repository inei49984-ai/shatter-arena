# SHATTER ARENA

Thomasを運転してドローンをアリーナの外へ吹き飛ばす3Dサバイバルゲームです。ページを開くとすぐに3Dロビーを表示し、軽量のThomasモデルで遊び始められます。高精細モデルはバックグラウンドで読み込み、届いた時点で切り替えます。

## ロビーとフレンド

- アカウント登録なし。名前と自分で決めるプレイヤーIDを登録します。
- 名前とIDはサーバー上で重複を防ぎます。IDは3〜16文字の英数字と `_` です。
- フレンドはIDで追加でき、オンライン状況を15秒ごとに更新します。追加は相互フレンドになります。
- プロフィールはブラウザーに保存されます。プレイヤー一覧とフレンド関係はサーバーの稼働中データとして扱います。

## 操作

- W / A / S / D または矢印キー: 走行
- マウス左ドラッグ: カメラ回転
- マウス右ドラッグ: カメラ移動
- マウスホイール: ズーム
- Space: 体当たり
- Q または Shift: 汽笛ブースト
- Esc: 一時停止
- スマートフォン: 左スティックで走行、画面ドラッグでカメラ、体当たり / 汽笛ボタンで攻撃

## ローカル起動

Node.js 20以降で実行します。

```sh
npm install
npm start
```

`http://localhost:3000` を開きます。Three.jsはアプリと同じサーバーから配信します。
